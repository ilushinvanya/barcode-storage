#### Процесс обновления
```
1. Пользователь открывает приложение
   ↓
2. Service Worker регистрируется и проверяет обновления
   ↓
3. Каждые 60 секунд автоматическая проверка
   ↓
4. При обнаружении новой версии:
   - Новый SW устанавливается (состояние: installing)
   - Переходит в состояние: installed (waiting)
   - Показывается уведомление пользователю
   ↓
5. Пользователь нажимает "Обновить" ИЛИ проходит 30 секунд
   ↓
6. Отправка сообщения SKIP_WAITING
   ↓
7. Новый SW активируется и берет управление
   ↓
8. Событие controllerchange → перезагрузка страницы
   ↓
9. Пользователь работает с новой версией
```

### Как использовать

#### Для разработчиков

**Обновление версии перед деплоем:**
```bash
# 1. Обновить версию Service Worker
npm run bump-sw

# 2. Собрать приложение
npm run build

# 3. Развернуть на сервере
# ... ваш процесс деплоя
```

**Тестирование локально:**
```bash
# 1. Первая сборка
npm run build
npm run preview

# 2. В другом терминале: обновить версию
npm run bump-sw
npm run build

# 3. Подождать 5-60 секунд
# 4. Увидеть уведомление о обновлении
```

#### Для конечных пользователей

**Автоматически:**
- Приложение проверяет обновления каждую минуту
- При обнаружении обновления показывается уведомление
- Можно нажать "Обновить" или подождать 30 секунд
- Страница перезагружается с новой версией

**Вручную (не требуется):**
- Пользователю не нужно ничего делать
- Все происходит автоматически

### Известные ограничения

1. **HTTPS требуется** для работы Service Worker (кроме localhost)
2. **Таймаут 30 секунд** для автообновления может быть настроен в `src/sw-register.ts`
3. **Проверка каждые 60 секунд** может быть изменена в `src/sw-register.ts`
4. **Fallback уведомление** используется если Vue не готов (редкий случай)

### Безопасность

- ✅ Service Worker работает только на HTTPS
- ✅ Кеширование только GET запросов
- ✅ Проверка валидности ответов перед кешированием
- ✅ Автоматическая очистка старых кешей

### Производительность

- ⚡ Размер `sw-register.ts`: ~3KB
- ⚡ Размер `update-notification.vue`: ~2KB  
- ⚡ Влияние на bundle: +5KB (минимальное)
- ⚡ Проверка обновлений: фоновая, не блокирует UI
- ⚡ Перезагрузка: мгновенная благодаря кешу

### Совместимость с предыдущими версиями

Все изменения обратно совместимы. Старые версии приложения:
- ✅ Продолжат работать с текущими данными
- ✅ Автоматически обновятся при следующем посещении
- ✅ Не потеряют данные из localStorage

### Миграция с предыдущей версии

Не требуется никаких действий. При первом посещении:
1. Старый service worker будет заменен новым
2. Старые кеши будут удалены
3. Новые кеши будут созданы
4. Данные пользователя сохранятся
