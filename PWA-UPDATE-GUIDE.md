# Руководство по обновлению PWA

## Как работает автоматическое обновление

Приложение автоматически проверяет наличие обновлений и предлагает пользователю обновиться при обнаружении новой версии.

### Механизм работы

1. **Service Worker регистрация** (`src/sw-register.ts`)
   - Регистрируется при загрузке страницы
   - Проверяет обновления каждые 60 секунд
   - Отслеживает события `updatefound` для обнаружения новых версий

2. **Стратегия кеширования** (`public/sw.js`)
   - **Network First** для навигационных запросов (HTML)
   - **Cache First** для статических ресурсов (JS, CSS, изображения)
   - Фоновое обновление кеша для актуальности данных
   - Версия кеша: `barcode-storage-v1.4`

3. **Уведомление пользователя** (`src/components/update-notification.vue`)
   - Красивое уведомление внизу экрана
   - Кнопки "Обновить" и "Позже"
   - Автоматическое обновление через 30 секунд при отсутствии действий

### Процесс обновления

```
Новая версия обнаружена
        ↓
Service Worker установлен (состояние: installed)
        ↓
Показывается уведомление пользователю
        ↓
Пользователь нажимает "Обновить" ИЛИ проходит 30 секунд
        ↓
Отправка сообщения SKIP_WAITING новому SW
        ↓
Service Worker активируется (skipWaiting)
        ↓
Событие controllerchange
        ↓
Перезагрузка страницы (window.location.reload)
        ↓
Новая версия активна
```

## Тестирование обновлений

### Локальное тестирование

1. **Запуск приложения**
   ```bash
   npm run build
   npm run preview
   ```

2. **Открыть в браузере**
   - Откройте DevTools (F12)
   - Перейдите на вкладку Application → Service Workers
   - Убедитесь, что SW зарегистрирован

3. **Симуляция обновления**

   **Способ 1: Изменение версии кеша**
   - Измените `CACHE_NAME` в `public/sw.js` (например, на `v1.5`)
   - Пересоберите: `npm run build`
   - Обновите страницу
   - Должно появиться уведомление об обновлении

   **Способ 2: Принудительное обновление в DevTools**
   - В DevTools → Application → Service Workers
   - Нажмите "Update" рядом с зарегистрированным SW
   - Если есть изменения, увидите новый SW в статусе "waiting"

4. **Проверка логов**
   ```javascript
   // В консоли должны появиться логи:
   [PWA] Service Worker зарегистрирован
   [PWA] Проверка обновлений...
   [PWA] Обнаружено обновление Service Worker
   [PWA] Состояние нового worker: installed
   [PWA] Новая версия доступна
   ```

### Тестирование на продакшене

1. **Развертывание новой версии**
   - Измените код приложения
   - Обновите версию кеша в `public/sw.js`
   - Соберите и разверните: `npm run build`

2. **Проверка обновления**
   - Откройте приложение на устройстве
   - Подождите до 60 секунд
   - Должно появиться уведомление о новой версии

3. **Проверка отката**
   - Если нужно вернуться к старой версии
   - Измените версию кеша обратно
   - Service Worker автоматически удалит новый кеш

## Отладка проблем

### Service Worker не регистрируется

```javascript
// Проверьте в консоли
if ('serviceWorker' in navigator) {
  console.log('Service Worker поддерживается');
} else {
  console.log('Service Worker НЕ поддерживается');
}
```

**Решение:**
- Убедитесь, что используете HTTPS (или localhost)
- Проверьте путь к `sw.js` (должен быть `/barcode-storage/sw.js`)

### Обновления не обнаруживаются

**Проверьте:**
1. Изменилась ли версия кеша `CACHE_NAME`
2. Прошло ли 60 секунд с последней проверки
3. Есть ли ошибки в консоли DevTools

**Принудительная проверка:**
```javascript
// В консоли браузера
navigator.serviceWorker.getRegistration().then(reg => {
  if (reg) reg.update();
});
```

### Уведомление не появляется

**Проверьте:**
1. Установлен ли старый SW (`navigator.serviceWorker.controller` должен существовать)
2. Есть ли функция `window.showPWAUpdateNotification`
3. Нет ли ошибок в консоли

**Отладка:**
```javascript
// Проверьте наличие функции
console.log(typeof window.showPWAUpdateNotification); // должно быть 'function'
```

### Старый кеш не очищается

**Решение:**
```javascript
// В консоли браузера
caches.keys().then(names => {
  names.forEach(name => {
    console.log('Cache:', name);
    if (name !== 'barcode-storage-v1.4') {
      caches.delete(name);
    }
  });
});
```

## Мониторинг в продакшене

### Рекомендуемые метрики

1. **Скорость обновления**
   - Время от обнаружения до активации
   - Процент пользователей, нажавших "Обновить"
   - Процент автоматических обновлений

2. **Ошибки**
   - Ошибки регистрации SW
   - Ошибки кеширования
   - Ошибки активации

3. **Использование кеша**
   - Размер кеша
   - Количество кешированных ресурсов
   - Hit rate кеша

### Логирование

Все ключевые события логируются с префиксом `[PWA]` или `[Service Worker]`:

```javascript
[PWA] Service Worker зарегистрирован
[PWA] Проверка обновлений...
[PWA] Обнаружено обновление Service Worker
[Service Worker] Installing...
[Service Worker] Activating...
[Service Worker] Removing old cache: barcode-storage-v1.3
```

## Рекомендации

1. **Версионирование**
   - Всегда изменяйте `CACHE_NAME` при деплое новой версии
   - Используйте семантическое версионирование (v1.4, v1.5, etc.)
   - Синхронизируйте с версией в `package.json`

2. **Тестирование**
   - Тестируйте обновления на staging перед продакшеном
   - Проверяйте на разных браузерах и устройствах
   - Используйте DevTools для симуляции медленной сети

3. **Пользовательский опыт**
   - Не заставляйте обновляться немедленно
   - Предоставьте кнопку "Позже"
   - Добавьте таймаут для автообновления (30 секунд)

4. **Безопасность**
   - Используйте HTTPS
   - Проверяйте integrity ресурсов
   - Регулярно обновляйте зависимости
