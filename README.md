# 📦 Barcode Storage

Простое и удобное веб-приложение для хранения и управления штрихкодами и QR-кодами. **Без регистрации, без SMS, без облачных серверов** — все данные хранятся локально в вашем браузере.

## 💡 Продуктовая идея

**Barcode Storage** — это приватное решение для хранения штрихкодов, которое работает полностью офлайн. Все ваши данные остаются на вашем устройстве в браузере, обеспечивая максимальную конфиденциальность и безопасность.

### Ключевые преимущества:
- 🔒 **Полная приватность** — данные хранятся только в вашем браузере
- 🚀 **Быстрая работа** — нет задержек на загрузку с сервера
- 📱 **Работает офлайн** — доступ к данным даже без интернета
- 🎯 **Простота** — никаких регистраций и сложных настроек
- 💾 **Надежность** — данные сохраняются в localStorage браузера

## ✨ Возможности

- 📷 **Сканирование с камеры** — используйте камеру устройства для сканирования штрихкодов в реальном времени
- 🖼️ **Сканирование с изображения** — загрузите фото со штрихкодом и получите его данные
- 🎨 **Визуализация** — автоматическая генерация изображений штрихкодов и QR-кодов
- ✏️ **Редактирование** — изменение названий сохраненных штрихкодов
- 🗑️ **Удаление** — удаление ненужных записей
- 📋 **Список всех штрихкодов** — удобный просмотр всех сохраненных кодов
- 📤 **Экспорт** — экспорт штрихкода в JSON формате через нативное Share API или копирование в буфер обмена
- 📥 **Импорт** — импорт штрихкода из JSON строки для быстрого добавления
- 🔄 **Автоматическое обновление PWA** — приложение автоматически проверяет наличие обновлений и предлагает обновиться

### Поддерживаемые форматы:
- QR Code
- EAN-13
- EAN-8
- Code 128
- Code 39
- Codabar
- UPC-A
- UPC-E

## 🛠️ Технологии

Этот проект был разработан с помощью [Cursor](https://cursor.sh/) — AI-powered редактора кода.

### Frontend:
- **Vue 3** — прогрессивный JavaScript-фреймворк для создания пользовательских интерфейсов
- **TypeScript** — типизированный JavaScript для повышения надежности кода
- **Vite** — быстрый инструмент сборки для современной веб-разработки
- **Tailwind CSS** — utility-first CSS фреймворк для быстрой стилизации

### Библиотеки:
- **jsbarcode** — генерация линейных штрихкодов (EAN, Code 128, Code 39 и др.)
- **qrcode** (node-qrcode) — генерация QR-кодов
- **Barcode Detection API** — нативное API браузера для распознавания штрихкодов

### Хранение данных:
- **localStorage** — локальное хранилище браузера для сохранения данных

## 🚀 Быстрый старт

### Требования
- Node.js 16+ и npm

### Установка

```bash
# Клонируйте репозиторий
git clone https://github.com/yourusername/barcode-storage.git

# Перейдите в директорию проекта
cd barcode-storage

# Установите зависимости
npm install
```

### Запуск

```bash
# Запуск dev-сервера
npm run dev

# Сборка для production
npm run build

# Просмотр production сборки
npm run preview

# Обновление версии Service Worker
npm run bump-sw
```

После запуска `npm run dev` приложение будет доступно по адресу `http://localhost:5173`

### Обновление PWA

Приложение автоматически обновляется при обнаружении новой версии. Подробнее об автоматических обновлениях смотрите в [PWA-UPDATE-GUIDE.md](PWA-UPDATE-GUIDE.md).

## 📖 Использование

1. **Создание нового штрихкода:**
   - Нажмите кнопку "+ Создать"
   - Выберите способ добавления:
     - Сканирование с камеры (требуется разрешение на доступ к камере)
     - Загрузка изображения со штрихкодом
     - Ручной ввод кода и формата
   - Введите название для штрихкода
   - Сохраните

2. **Просмотр штрихкодов:**
   - Все сохраненные штрихкоды отображаются в списке
   - Нажмите на штрихкод для просмотра деталей

3. **Редактирование:**
   - Нажмите на иконку редактирования рядом с названием
   - Измените название и сохраните

4. **Удаление:**
   - Нажмите на иконку удаления
   - Подтвердите удаление

5. **Экспорт штрихкода:**
   - Откройте нужный штрихкод
   - Нажмите на иконку экспорта (зеленая иконка с стрелками)
   - Выберите способ экспорта:
     - **Нативное Share API** (на мобильных устройствах) — откроется диалог для отправки через приложения
     - **Копирование в буфер обмена** — JSON строка будет скопирована автоматически
   - Экспортированный JSON содержит поля: `name`, `format`, `code`

6. **Импорт штрихкода:**
   - Нажмите кнопку "+ Создать"
   - В верхней части формы найдите поле "Импорт из JSON"
   - Вставьте JSON строку в формате:
     ```json
     {
       "name": "Название штрихкода",
       "format": "qr_code",
       "code": "123456789"
     }
     ```
   - Нажмите кнопку "Импорт"
   - Поля формы автоматически заполнятся данными из JSON
   - Проверьте данные и нажмите "Сохранить"

## 🌐 Совместимость браузеров

Приложение использует **Barcode Detection API**, который поддерживается в:
- Chrome/Edge 83+
- Opera 69+
- Android Chrome

Для других браузеров доступен ручной ввод штрихкодов.
